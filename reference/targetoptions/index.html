Enemy Health Options

Section titled “Enemy Health Options”

Note that all enemy options should only be specified after you declare an enemy.

Fixed Health Percentage

Section titled “Fixed Health Percentage”

Using enemy_fixed_health_percentage sets the enemy’s health to a fixed percentage that will not change over the course of the sim.

Initial Health Percentage

Section titled “Initial Health Percentage”

Using enemy_initial_health_percentage sets the enemy’s health to start at a certain percentage. The percentage should be entered as a whole number.

Initial Health

Section titled “Initial Health”

Using enemy_health will allow you to set the starting health of the enemy, instead of having the sim calculate the enemy’s health automatically.

Enemy Death Percentage

Section titled “Enemy Death Percentage”

Using enemy_death_pct you can tell the sim to kill the enemy early, like in the case of Ragnaros where he dies at 10% like a pansy.

TMI Standard Bosses

Section titled “TMI Standard Bosses”

The default boss (Fluffy_Pillow) uses a mixture of abilities, but isn’t regularly adjusted to content levels. For tanks, there are a set of “standard” bosses that are designed for generating reliable/repeatable TMI scores for tanks. These can be invoked by setting the tmi_boss option.

The format of this option is

T<tier #><difficulty><raid format>,

so for example T15N10 for the tier 15 10-man normal boss, T15H25 for the tier 15 25-man heroic boss, and so on. If the <raid format> is left blank, 25-man is assumed.

Assigning a tank to enemy

Section titled “Assigning a tank to enemy”

You can use enemy_tank option to assign a target for this enemy.

Sim-wide Target Level

Section titled “Sim-wide Target Level”

The option target_level allows you to specify what level all targets in the simulator should be. The default is three levels higher than the highest level character in the sim, normally 88.

Sim-wide Target Race

Section titled “Sim-wide Target Race”

The target_race options allow you to specify what race all targets in the simulator are to kick in the effects of certain talents. (Exorcism for example.)
